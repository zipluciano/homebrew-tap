# zipluciano/homebrew-tap

Homebrew casks for tools published by [@zipluciano](https://github.com/zipluciano).

## Install

```sh
brew install --cask zipluciano/tap/<cask>
```

Use the full name (`zipluciano/tap/<cask>`): Homebrew trusts a cask from a third-party tap when you
install it by its full name, so nothing else has to be configured. After that, upgrades work as usual
with `brew upgrade`.

## Maintenance

Casks are generated by each project's release workflow (GoReleaser) and committed here automatically.
Do not edit them by hand: change the project's release configuration instead. Report problems in the
project's own repository.

To add a project, publish its cask to `Casks/` from its release workflow and add a row to the table above.

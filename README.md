# zipluciano/homebrew-tap

Homebrew casks for tools published by [@zipluciano](https://github.com/zipluciano).

```sh
brew install --cask zipluciano/tap/finnick
```

| Cask | Description |
| --- | --- |
| [finnick](https://github.com/zipluciano/finnick) | Local web UI for secrets kept with SOPS and age |

Casks are generated by each project's release workflow; do not edit them by hand. Report problems in the
project's repository.
